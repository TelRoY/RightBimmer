# RightBimmer

Сервис по покупке, доставке и растаможке автомобилей из Японии

## О проекте

Современное веб-приложение, разработанное для помощи в покупке автомобилей с японских аукционов в личное пользование. Проект предполагает полный цикл услуг: от подбора авто до его доставки. 

## Статус разработки:

⚠️ Проект находится на стадии активной разработки
На данный момент реализован статический макет главной страницы. В ближайших планах — добавление полноценного функционала.

## Планы по развитию

### Ближайшие задачи:

1. Калькулятор стоимости

Расчёт на основе введённых параметров (модель, год, объём двигателя, город доставки)

Отображение полной стоимости с разбивкой по статьям расходов

2. База данных

Хранение информации об автомобилях клиентов

История заказов и статусы доставки

Система отслеживания

3. Личный кабинет

Регистрация и авторизация пользователей

Просмотр и управление заказами

4. Каталог автомобилей

Фильтрация по марке, модели, году, пробегу, цене

Детальная карточка автомобиля

5. Интеграция с японскими аукционами

Получение актуальных данных с аукционов

Автоматический поиск и подбор автомобилей
