# RightBimmer

Сервис по покупке, доставке и растаможке автомобилей из Японии

## О проекте

Современное веб-приложение, разработанное для помощи в покупке автомобилей с японских аукционов в личное пользование. Проект предполагает возможность выбора авто и расчета его стоимости с доставкой в ваш город.

## Статус разработки:

⚠️ Проект находится на стадии активной разработки
На данный момент реализовано:

- полноценное SPA-приложение;
- калькулятор стоимости авто на основе введённых параметров (модель, год, объём двигателя, город доставки);
- отображение полной стоимости с разбивкой по статьям расходов.

В ближайших планах:

- доработка дизайна проекта;
- создание базы данных авто с их подробными характеристиками;
- возможность создания личного кабинета с функционалом сохранения в избранное понравившихся автомобилей;
- возможность обратной связи и оставление заявки на участие в аукционе;
- интеграция с японскими аукционами.

## Планы по развитию

### Ближайшие задачи:

1. База данных

Хранение информации об автомобилях с фотографиями, описанием и подробными характеристиками

2. Личный кабинет

Регистрация и авторизация пользователей

Обратная связь

Добавление понравивишихся автомобилей в категорию "Избранное"

3. Каталог автомобилей

Фильтрация по марке, модели, году, пробегу, цене

Детальная карточка автомобиля

4. Интеграция с японскими аукционами

Получение актуальных данных с аукционов

Автоматический поиск и подбор автомобилей
